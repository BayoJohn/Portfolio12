When you edit a document, several parts of your computer work together. The app gives you a place to type, the operating system manages the work, and storage keeps the file after the device shuts down. Knowing which part does what gives you a starting point when something feels slow or a file seems to disappear.

## What you’ll learn

You’ll distinguish the processor, memory and storage, then follow a file from a folder into an app. You’ll also practise describing a simple problem so someone else can help you troubleshoot it.

## Prerequisites

Use a computer or tablet where you can open a file manager and a text editor or notes app. Choose a file you can safely copy, or make a short practice document. You can do the exercise with your ordinary account.

## What keeps a program running?

**The processor**, often called the CPU, carries out instructions. Recalculating a spreadsheet or compressing a file gives the processor work to do.

**Memory**, usually called RAM, holds information the system and its running apps are actively using. Closing an app can free some of this working space. Save changes you want to keep before closing an app.

**Storage** keeps files and installed apps available after shutdown. When storage is nearly full, saving files or installing updates can become difficult. Freeing space on a drive addresses storage pressure. Closing unused apps can help when the system runs short of memory.

## How apps, files and the operating system fit together

The operating system manages access to hardware and helps programs work with resources such as files, the network and the display. An app is a program you use for a task. A file is a saved item that an app may read or change.

Opening a document loads information from storage into a running app. Editing changes the document you see in the app. Saving writes those changes back to the file. Some apps save automatically, and cloud-backed folders may also sync a saved copy to a service. These behaviours depend on your app and settings.

A folder gives a file a location. A path describes that location, including whichever folders contain it. Two files can share a name if they live in different folders, so the folder is often as important as the filename.

## Try it with a practice file

1. Create a folder named **Practice** inside your Documents folder or another location you can find again.
2. Make a short text document, save it in **Practice**, then close the app.
3. Open the file from the folder. Add a line, save, and reopen it to check that the change persisted.
4. Make a copy in another folder. Change only the copy and compare both files. Pay attention to the location shown by the file manager or the app’s save dialog.

If you can see the app but cannot find the file, start by checking the app’s recent files and the last folder you used. If someone else is helping, give them the filename, the expected folder and the exact message you saw. Those details give them something concrete to check.

## Key takeaways

The processor executes instructions, memory gives running apps working space, and storage keeps saved files. When you cannot find a document, start with its name and location. When an app is slow, note what you were doing and whether the slowdown affects one app or the whole device.
