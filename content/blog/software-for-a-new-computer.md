A new computer gives you a rare chance to choose the apps you use on purpose. Start with three things you do every week. The browser and file manager your computer ships with may already cover two of them. Install a new app when you can describe the gap it fills and know where you’ll get updates.

## Start with the files you already have

LibreOffice covers documents, spreadsheets and presentations offline. Its own formats are a reasonable choice for work you control. If a colleague sends a complex Word template or a spreadsheet with macros, round-trip a copy. Open the file, save it in the required format, then ask the recipient to open it in their usual software. For a report that no one else needs to edit, exporting to PDF can preserve the final layout.

VLC is useful when your default media player struggles with a file. OBS Studio serves a different purpose. It combines capture sources into a scene for recording or streaming. Set up a short recording and play it back before relying on it for a lesson or meeting. Check that the intended microphone is present and that notifications or private windows are out of frame.

## Add tools for the jobs you do regularly

Use calibre if your local ebook collection needs better organisation, or if you work with unprotected books in several formats. KDE Connect can help move files between paired devices. Read its platform notes first, since the available features differ across operating systems. For a computer you share, decide where shared files should live and how each person will back up their own work.

## Keep the list small

Install through the publisher or a trusted system store. Keep one app for each job until you discover a specific limitation. If an app is only needed for a single project, remove it when you finish. A short list of installed tools is easier to maintain and easier to move to another computer.
