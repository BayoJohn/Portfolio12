Whether Linux can replace Windows depends on the tasks that would stop your week if they broke. The useful test is to list those tasks before you touch the installer. A web app for coursework is one kind of dependency. A Windows-only proctoring tool, a specific game or a spreadsheet tied to a desktop add-in is another.

## Make a compatibility list

Write down the exact software and accessories you rely on, including a printer, camera or work VPN. Check the vendor’s support page for the model or application. If a Linux version exists, find out whether it has the features you need. If a browser version is your fallback, try the same workflow there first. You can do that while still running Windows.

## Try a live session

Canonical documents how to start Ubuntu from a USB drive in live mode. Creating the installation media can erase the USB drive, so use one you can clear. Back up your important files and choose the option to try Ubuntu rather than starting the installation. Test Wi-Fi, audio, external displays, keyboard shortcuts and a sample document. A successful live session gives you useful compatibility evidence, although it cannot establish that every update or accessory will behave the same after installation.

## Keep an easy way back

If most of your work is portable, test on a spare device or keep your existing computer available through a full project. If one essential tool remains Windows-only, keeping Windows for that workload can save time. Virtual machines and compatibility layers take setup and sometimes have limits around graphics, USB devices or organisation policy.

When the basic workflow works, add software through Ubuntu’s supported repositories or vendor instructions. For file navigation and basic troubleshooting, the existing [Tech Academy terminal guide](../../academy/linux-terminal-essentials/) is a useful companion.
