Microsoft released KB5132057 on November 19 as a preview for Windows 11 versions 25H2 and 26H2. It includes a revised Search experience. Microsoft lists that experience under gradual rollout and says it is initially available in English. Installing the update and seeing the feature can therefore happen at different times.

## What changes in Search

Microsoft describes a single list for results, previews of files, and actions that can be completed without opening a separate Settings screen. Someone who regularly opens Search just to adjust brightness or find the location of a recent file may find the new arrangement useful. Microsoft also lists changes to search from This PC in File Explorer. Those are separate surfaces, even though both help you locate files.

## Decide whether you need the preview

This is an optional non-security preview. Readers with a computer they need for a deadline can weigh the benefit of the new feature against the value of keeping their normal update schedule. Check your Windows edition and version in Settings and use Windows Update or the process your administrator supplies. If your device already shows the listed build but Search still looks familiar, the gradual rollout is one possible explanation.
