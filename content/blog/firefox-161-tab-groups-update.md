Firefox 161 reached the desktop Release channel on November 24. The most useful change for people juggling several tasks may be a small one: tab groups now appear in the application menu. That gives a saved group a more predictable place to return to after closing it.

## A quicker way back to a task

Groups are useful when several tabs belong to the same job, such as reading a set of vendor documents or comparing quotes. A direct way to reopen the set can reduce the temptation to leave everything running in the tab bar. Mozilla also added an optional shortcut for copying the current tab’s address. No key combination comes assigned. If you set one, check that the shortcut is easy to reach and does not overlap with another action you use.

## Check how your installation updates

Mozilla’s notes also list fixes for certain video calls, session restoration and a bookmark-related hang on macOS. Readers on a distribution package or a browser managed by work or school may receive the release on a different schedule. Use the browser or system’s normal update channel and check the installed version before looking for new controls.
